About me

I build web and mobile applications with AI inside them. That usually means an assistant that answers from a company's own documents, a feature that understands what someone typed instead of making them fill in a form, or an agent that quietly handles a multi-step job in the background. The model is rarely the hard part. Deciding what the product should do when the answer isn't obvious is.

Eight years of web development came first, and that is what makes the AI half work. A model sitting in a notebook isn't finished. Putting it in front of real users means an interface worth using, an API that holds up, and infrastructure the next person can maintain.

I'm comfortable across the stack, from React and Vue on the front end to Node, Laravel and Python behind it. I work quickly without cutting corners, and I'd rather raise an awkward question early than find the problem at launch.

What i'm doing

  • AI-powered web apps

    Web applications with a model doing real work inside them: answering from your own documents, understanding what someone typed, or handling a step that used to need a person. I build the whole thing, so the AI part arrives as a working product rather than a demo.

  • AI agents & automation

    Software that decides its own next step. I give an agent the tools it needs, set sensible limits on what it can do, and connect it to the systems a team already works in, so it fits the existing workflow rather than replacing it.

  • Mobile apps

    iOS and Android applications, built natively or with React Native and Flutter. The same approach applies here: if a model belongs in the app, it ships as part of the product rather than bolted on afterwards.

  • Machine learning

    Training and deploying models when an off-the-shelf API isn't the right answer. That includes the unglamorous half: cleaning the data, working out whether the results are genuinely good, and keeping the model running once it's live.

  • Web design

    Interface and layout work for the applications I build, and for teams who have the engineering covered but want the product to look considered. Clean, responsive, and designed around what people actually do with it.
